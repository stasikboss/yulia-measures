# עולם המידות של יוליה

משחק לימודי בעברית לכיתה ו׳ על יחידות מידה: מסה, נפח, אורך וזמן.

**לשחק עכשיו:** https://stasikboss.github.io/yulia-measures/

## מה יש במשחק
- **לומדים** – ניסויים אינטראקטיביים: משקל עם תפוחים ושקיות סוכר, כוס שנמזגת לקנקן, סרגל וסוסה על שביל של 2 ק״מ, שעון מחוגים, יממה ושבוע.
- **מתרגלים** – 14–15 שאלות בכל תחנה: המרה, בחירה, השוואה וגרירה.
- **אתגר** – 9 בעיות מילוליות מהחיים בכל תחנה.
- רמז גרפי בכל שאלה, כוכבים, מדליות, ושמירת התקדמות במכשיר.

## התקנה בטלפון
פותחים את הקישור בכרום ← תפריט ⋮ ← „הוספה למסך הבית”.

קובץ אחד (`index.html`), בלי הרשמה, בלי פרסומות, עובד גם בלי אינטרנט.
